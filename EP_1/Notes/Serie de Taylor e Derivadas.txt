- Serie de Taylor e Derivadas:

Função: 
	F(X) = tan(x)

Principais propriedades da nossa Função:
- Não é limitada.
- Período: PI
- Singularidade: Assíntotas vertical X = +- PI/2, +- 3PI/2,...

Expandimos a função em torno de Maclaurin
	tan(x) = m=0∑∞[​[ {(F^(m)) * (0)} / m!] * x^m]

Como na pratica só aparecem potencias impares, vamos escrever
	
	tan(x) = k=1∑∞[ck * (x^(2k-1))]

sendo ck = [{F^(2k-1) * (0)} / (2k-1)!].

A derivada dá nossa função é:
	F(x) = tan(x)
	F'(x) = sec²(x)
	F''(x) = 2tan(x) * sec²(x)
	F'''(X) = 2senc²(x) * (1 + 3tan²(x))

Avaliando nossa derivadas, temos:
F(0) = tan(0) = 0
F'(0) = sec²(0) = 1
F''(0) = 2tan(0) * sec²(0) = 0
F'''(0) = 2senc²(0) * (1 + 3*tan²(0)) = 2

Com isso a extração dos coeficientes ck é utilizando a números de Bernoulli:
Para os primeiros termos temos:
c1 = 1 (porque f'(0) = 1 e (1!/1!) = 1)
c2 = 1/3 (porque f'''(0) = 2 e (2/3!) = (2/6) = (1/3))
...

- Resto de Taylor e critérios para escolher N:

Resto de Lagrange:
O resto quando truncamos em ordem N é:
RN (x) = [{F^(N+1)*(£)} / (N+1)!] * (x^(N+1)), Com £ pertencendo (0, x)
sabemos que para x = PI/4 tan(x) = 1.
com N = 10 o erro é 10^-6, que é o suficiente.
